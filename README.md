# 🍰 Cake Shop Website

A simple static website for a cake shop, built using HTML and CSS. This project was created as part of my early learning in frontend development to practice basic layout and styling techniques.

---

## 📌 Overview

This website represents a basic cake shop layout, including sections for showcasing products, information, and design structure. The goal of this project was to understand how to structure a webpage and apply styling using pure CSS.

---

## 🛠️ Built With

* HTML5
* CSS3

---

## ✨ Features

* Simple and clean layout
* Basic styling using CSS
* Structured sections for a shop-style website

---

## 🚧 Limitations

* Not responsive (optimized for desktop only)
* No JavaScript or interactivity
* Basic design (learning project)

---

## 🎯 Purpose

This project was built to:

* Practice HTML structure
* Learn CSS styling and layout
* Take the first step into frontend development
